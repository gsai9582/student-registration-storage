# Student Registration & Data Storage System

A web-based student information registration and data persistence system built with responsive HTML5/CSS3 and a relational database backend.

## 🚀 Key Features

- **Form Validation:** Client-side HTML5 & JavaScript validation ensuring data completeness.
- **Persistent Storage:** Relational database storage supporting SQLite and MySQL backends.
- **Dynamic Reporting:** Real-time student directory table fetching and rendering stored records.
- **Responsive Layout:** Clean CSS3 styling optimized across desktop and mobile screens.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** PHP 8+
- **Database:** MySQL / SQLite (`student.db`, `database.sql`)

## 💻 Setup & Installation

1. Clone this repository into your local web server root (e.g. `htdocs` for XAMPP):
   ```bash
   git clone https://github.com/gsai9582/student-registration-storage.git
   ```
2. Import `database.sql` into MySQL / phpMyAdmin or use the local SQLite database.
3. Access the portal in your browser:
   ```
   http://localhost/student-registration-storage/index.php
   ```
